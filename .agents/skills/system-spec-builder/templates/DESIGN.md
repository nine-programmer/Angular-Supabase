## 3. Component patterns [LOCKED]

เขียนเป็น Tailwind class ตายตัว copy ไปใช้ได้เลย (เปลี่ยนเฉพาะข้อความ) — pattern ที่ใช้ซ้ำ 2+ feature ให้ทำเป็น component ใน `src/app/ui/` ตาม AGENTS.md

### ปุ่ม

- หลัก: `[class เต็ม]`
- รอง: `[class เต็ม]`
- อันตราย (ลบ/ยกเลิก/ปฏิเสธ): `[class เต็ม]`
- ทุกปุ่มต้องมี focus ring (`focus-visible:ring-2 ...`) — ห้ามลบ outline โดยไม่มีตัวแทน

### ฟอร์ม

- label: `[class]` — ทุกช่องกรอกมี `<label for>` มองเห็นได้เสมอ
- input/select/textarea: `[class ปกติ]` / `[class ตอน error]`
- ข้อความ error ใต้ช่อง: `[class]` + `role="alert"`

### ป้ายสถานะ (badge)

สี + ข้อความไทยเสมอ ห้ามสื่อด้วยสีอย่างเดียว — ค่าตรงกับ enums ใน `src/shared/enums/`

| สถานะ   | class          | ข้อความ   |
| ------- | -------------- | --------- |
| [value] | `[class เต็ม]` | [ป้ายไทย] |

### รายการข้อมูล

- มือถือ (< `md`): การ์ด `[class]` · จอกว้าง (`md:` ขึ้นไป): [ตาราง `[class]` / การ์ดเหมือนเดิม]
- empty state: `[class]` + ข้อความ [เช่น "ยังไม่มีรายการ"]
