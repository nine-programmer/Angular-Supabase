# EXTENSION POINTS — จุดขยายของ template `Angular-Supabase` เมื่อระบบต้องการมากกว่า CRUD

> ไฟล์นี้เป็นของ **template** (แยกออกมาจาก `docs/ARCHITECTURE.md` ข้อ 9 เพื่อไม่ให้โหลดทุกครั้ง) ห้ามแก้ในโปรเจกต์ลูกค้า
> อ่านเฉพาะเมื่อ SPEC ต้องการความสามารถในตารางนี้ (login, endpoint สาธารณะที่เขียนข้อมูล, อัปโหลดไฟล์, แจ้งเตือน, งานตามเวลา, รายงาน, SSE, audit, พิมพ์, resource > 5)

ความต้องการที่ template-scope จัดเป็น "พอดี แต่ต้องตัดสินใจ" มีที่วางไฟล์กำหนดไว้แล้ว — โฟลเดอร์/ชื่อไฟล์ในตารางนี้ถือว่าอยู่ในผัง ARCHITECTURE.md ข้อ 3 แล้ว **ไม่ต้องถามผู้ใช้ก่อนสร้าง** แค่ระบุใน SYSTEM_SPEC 2.3/2.4 ว่าใช้ตัวไหน และยังคงกติกาเดิม: browser ไม่แตะ Supabase, ทุกอย่างผ่าน `/api/*`
